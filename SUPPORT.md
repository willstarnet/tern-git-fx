# Getting help

- **How do I ...?** Check the [README](README.md) (configuration, aliases, what counts as a git
  command), then open a
  [question](https://github.com/willstarnet/tern-git-fx/issues/new?template=question.md).
- **Something is broken.** Open a
  [bug report](https://github.com/willstarnet/tern-git-fx/issues/new?template=bug_report.md) with
  the plugin and Tern versions, your OS and the steps. Remove personal paths, hostnames and
  command lines from logs you paste.
- **An idea.** Open a
  [feature request](https://github.com/willstarnet/tern-git-fx/issues/new?template=feature_request.md).
- **Security.** Privately, as [SECURITY.md](SECURITY.md) describes.
- **Tern itself** (crashes, sign-in, the plugin API): see the
  [Tern docs](https://docs.stencil.so/tern/).
